## TOEIC Studio

Web admin đã deploy: https://toeic-api-production-8b44.up.railway.app

- Database: [schema MySQL](TOEICStudio/backend/schema.sql), migration và seed.
- Backend: JWT, API học viên/admin, luyện tập và thi thử, tiến độ và thống kê.
- Admin: CRUD từ vựng/ngữ pháp/câu hỏi/đề thi và dashboard.
- [Hướng dẫn chạy và deploy](TOEICStudio/README.md).
- [Tài liệu API](TOEICStudio/API.md).

Chạy lệnh trong thư mục `TOEICStudio`. Nếu deploy service từ repository này, chọn root directory `/TOEICStudio`. Thông tin đăng nhập, file .env và database runtime không được đưa lên GitHub.
